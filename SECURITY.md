# Security policy

## Reporting a vulnerability

Report security problems in wp-doctor privately through GitHub's "Report a
vulnerability" option on the Security tab of this repository. Please do not open
a public issue. Expect an acknowledgement within a few days.

## Scope

In scope: ways a scanned site could harm the machine running wp-doctor, ways
wp-doctor could write to a site or database, and ways it could leak credentials
in its output.

## Intended use

wp-doctor is for sites you own or administer. It performs no network scanning of
third-party sites.
